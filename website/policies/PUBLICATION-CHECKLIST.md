## Evidence boundaries

Official OpenAI documentation says API training use requires opt-in. Its documented
abuse-monitoring default is up to30days with stated legal/safety exceptions;
application state and other feature-specific storage are separate. This describes
the provider documentation, not this organization's settings. Do not claim Zero
Data Retention, no provider retention or a processing country without applicable
account evidence. Source: [OpenAI data controls](https://developers.openai.com/api/docs/guides/your-data),
reviewed September28UTC. Before final publication, recheck the applicable endpoints,
models, agreements and selected account controls.

Do not save API keys, session tokens, private request bodies, customer messages or
unredacted account screenshots in the public review package. Record only the
necessary setting, scope, method/time and private evidence reference. A selected
project's display name alone does not prove that the deployed credential uses it.
If that binding cannot be established with existing safe metadata, keep it pending.
